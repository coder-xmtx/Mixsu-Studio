## 技术栈

| 包管理器 | 前端全栈框架 | UI框架  |   博客渲染   |
| :------: | :----------: | :-----: | :----------: |
|   Bun    | Nuxt4 (Vue3) | Nuxt UI | Nuxt Content |

开发编辑器：VS Code

## 开发构建

依赖下载：

```bash
bun install
```

启动服务端口 `http://localhost:3000`:

```bash
bun run dev
```

构建：

```bash
bun run build
```

构建预览：

```bash
bun run preview
```
